The Project
How it's built

This tool segments customers using a K-Means clustering model built with Scikit-learn and served through FastAPI. 14 behavioral and demographic features are scaled using StandardScaler and fed into the clustering algorithm, which discovers 4 distinct customer groups. The model is serialized with Joblib and served via a REST API.

#1

Data Pipeline

5,000 customer records processed and cleaned. Feature engineering creates derived metrics like spending per visit and engagement score.

#2

Feature Engineering

14 numerical features selected and scaled. StandardScaler ensures distance-based clustering treats all features equally.

#3

ML Pipeline

K-Means trained with K=4. Optimal clusters determined via Elbow Method and Silhouette Score analysis.

#4

Deployment

FastAPI backend deployed on Render. Frontend served via Netlify. Model and scaler persisted with Joblib.
